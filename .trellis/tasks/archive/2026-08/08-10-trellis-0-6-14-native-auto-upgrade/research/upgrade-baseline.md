## Customization Audit

- `.trellis/config.yaml` explicitly uses journal commit message
  `chore: record journal`, rotates at 2,000 lines, and protects channel workers
  with `idle_timeout: 5m` and `max_live_workers: 6`.
- The old Codex configuration documents inline as the default and only registers
  `UserPromptSubmit`; it lacks the 0.6.14 native SubagentStart injection.
- `.trellis/.template-hashes.json` had already removed stale hash entries for
  deleted `trellis-spec-bootstarp` templates. This is updater metadata and will
  be accepted only as part of the final 0.6.14 manifest.
- Because those stale hash entries were absent, the updater could not prove
  ownership of the two typoed skill directories and skipped their automatic
  migration. Git confirmed all ten old files were unchanged from `HEAD`; the
  upgrade therefore removed those generated directories explicitly after the
  correctly named `trellis-spec-bootstrap` replacements were installed.
