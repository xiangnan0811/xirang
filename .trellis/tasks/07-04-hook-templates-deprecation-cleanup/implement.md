# Hook Templates Deprecation Cleanup Implementation Plan

> Inline Trellis execution: the main Codex session implements and checks this
> plan directly. Use TDD for behavior changes and keep commits focused.

**Goal:** Remove the deprecated hook-template API/UI path while preserving manual
policy hooks and app-aware backup profiles.

**Architecture:** Delete the legacy route and frontend consumer, then refresh
generated docs and user documentation. Tests lock both sides: router route
absence/preserved replacement route, and policy editor no longer requesting or
rendering hook templates.

**Tech Stack:** Go 1.26, Gin router tests, React 18, TypeScript 5.8, Vitest,
Testing Library, Swagger generated by `swag init`.
