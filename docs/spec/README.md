# 开发合同

本目录维护 Xirang 当前的开发、兼容与回归要求，适用于所有贡献者和编码工具。
[项目入口](../../AGENTS.md) 定义权威和加载范围，[贡献指南](../../CONTRIBUTING.md)
定义环境、命令与交付流程。按任务进入相关层，再读具体合同。

- [后端](backend/README.md)：目录、数据库、错误、日志、质量和部署运行时。
- [前端](frontend/README.md)：组件、Hook、状态、类型与可访问性。
- [领域](domains/README.md)：跨持久化、API、前端的业务约束和回归场景。
- [指南](guides/README.md)：架构、协作、测试和文档维护。

行为或兼容承诺变化时更新其唯一主文，并保留源码、测试证据和必要回归场景。
用户操作见 [管理员指南](../admin/README.md)，发布及自动化见
[维护者指南](../maintainers/README.md)。
