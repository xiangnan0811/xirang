# Snapshot File Search

> 跨快照文件搜索功能，用于在历史 restic 快照中快速定位文件。

## 概述

Snapshots File Search 允许用户在某个 restic 类型任务的所有历史快照中按文件名/路径搜索文件，
帮助快速定位某个文件存在于哪些快照中，一键跳转到快照文件浏览器进行查看或恢复。

## 使用方式

1. 在任务列表页，点击某个 restic 任务的「执行历史」按钮。
2. 在弹出的执行历史对话框中，点击「搜索文件」按钮。
3. 在搜索框中输入文件名关键词（如 `nginx.conf`、`data/backup` 等）。
4. 系统会自动在后台构建文件索引（首次搜索），或更新增量索引。
5. 搜索结果将显示匹配的文件路径、所在快照和文件大小。
6. 点击搜索结果行，将自动跳转到该快照的文件浏览页面，可直接查看文件目录并进行恢复操作。

## 索引机制

- **按需构建（Lazy Indexing）**：首次搜索某个 task 时，系统会在后台运行 `restic ls --json` 获取该 task 所有快照的文件清单，并构建索引。
- **增量更新**：后续搜索时，系统会检测是否有新快照，如有则仅对新增快照进行增量索引。
- **构建中提示**：索引构建期间，搜索 API 会返回 `{status: "indexing"}` 状态，前端会显示「索引构建中」提示，用户稍后重试即可获取结果。

## 限制

- **仅支持 restic 类型任务**：搜索功能基于 restic 的快照文件清单，不适用于 rsync/rclone/command 类型任务。
- **路径搜索（非全文搜索）**：搜索范围为快照中的文件路径，不支持搜索文件内容。
- **最多返回 200 条结果**：单次搜索结果有上限，如需更精确的结果请使用更具体的关键词。
- **不支持正则表达式**：搜索使用 SQL `LIKE` 运算符进行前缀/后缀/包含匹配。

## API

### GET /api/v1/tasks/:id/snapshots/search?q=<keyword>

- `q`：搜索关键词（必填，不能为空）
- 响应：
  - 索引构建中：`{status: "indexing", message: "..."}`
  - 索引就绪：`[{snapshot_id, path, size, mtime}]`
- 错误：
  - 空关键词：400
  - 非 restic 任务：400
  - 任务不存在：404
