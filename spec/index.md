# Development contracts

Start with the layer affected by the change; load individual contracts on demand.
These files apply to every contributor, independently of coding tools or a
personal harness. [AGENTS.md](../AGENTS.md) owns project entry and delivery rules;
[CONTRIBUTING.md](../CONTRIBUTING.md) provides contributor commands.

- [Backend](backend/index.md): Go services, API, data, migrations and deployment.
- [Frontend](frontend/index.md): React components, types, state and accessibility.
- [Shared guides](guides/index.md): branch workflow, reuse and documentation truth.
- [Agent collaboration](guides/agent-collaboration.md): authorized parallel work,
  independent review, recovery identity and verification evidence.

Update existing contracts when behavior or compatibility commitments change.
Keep source/test references and required regression cases current. Historical
plans and session records are not prerequisites for ordinary development.
